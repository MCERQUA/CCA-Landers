# Changelog

All notable changes to the CCA Interactive Map Component will be documented in this file.

## [1.0.0] - 2024-08-16

### Initial Release
- 🎯 Interactive US map with all 50 states
- 🔗 Direct links to CCA contractor insurance pages
- 🎨 Customizable colors and behaviors
- 📱 Responsive design for all devices
- 🚀 Zero dependencies, pure JavaScript
- 📦 Multiple integration methods (CDN, NPM, self-hosted)
- 📝 Comprehensive documentation

### Features
- Hover effects with state highlighting
- Tooltips showing state names and availability
- Color-coded states (available vs coming soon)
- Custom click handlers for analytics
- Loading animations
- Error handling for missing containers
- Keyboard navigation support (planned for v1.1.0)

### States Available at Launch
36 states with active contractor insurance pages:
- Alabama, Alaska, Arizona, California, Colorado
- Delaware, Florida, Georgia, Illinois, Indiana
- Kentucky, Louisiana, Maine, Maryland, Massachusetts
- Michigan, Minnesota, Mississippi, Montana, Nevada
- New Mexico, New York, North Carolina, North Dakota
- Ohio, Pennsylvania, South Carolina, South Dakota
- Tennessee, Texas, Utah, Virginia, Washington
- West Virginia, Wisconsin

- None reported
